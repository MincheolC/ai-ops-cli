# `$pc:next` 우선순위 저장 흐름 추가

## Summary

`pc`에 `$pc:next`를 추가해 “다음 세션에서 바로 이어서 할 우선순위 목록”만 가볍게 저장한다. 별도 독립 skill은 만들지 않고, 기존 `pc` skill과 CLI write helper에 붙인다. 사용자가 여러 항목을 주면 전체 목록은 active workstream의 남은 우선순위로 저장하고, 첫 번째 항목은 `다음 첫 행동`으로 저장한다.

## Key Changes

- 새 CLI 표면을 추가한다: `ai-ops pc next --cwd <path> --item <text> --item <text> --basis <text>`.
- 새 core 함수는 현재 cwd 기준 pc readiness를 확인하고, active workstream과 current entry가 없으면 실패한다.
- 저장 규칙은 고정한다:
  - `--item`은 1개 이상 필수이며 trim 후 빈 값은 버린다.
  - 첫 번째 item은 `## 다음 첫 행동`에 저장한다.
  - 전체 item 목록은 active workstream의 `남은 일` 섹션에 `ai-ops:pc-next` managed block으로 저장한다.
  - `--basis`는 `다음 행동 근거`로 저장하며 필수다.
  - product repo와 `마지막 확인 Commit`은 갱신하지 않는다.
- context repo 변경은 기존 guard를 재사용한다:
  - context root는 git repo여야 한다.
  - allowed files는 active workstream과 `backlog.md`로 제한한다.
  - managed files에 기존 dirty change가 있으면 실패한다.
  - 변경이 있으면 context repo에서만 `Record next priorities: <workspaceId> <workstreamId>`로 commit한다.
- `pc` skill 문서를 갱신한다:
  - invocation 목록에 `$pc:next` 추가
  - `$pc:todo`는 계속 read-only
  - `$pc:next`는 active workstream의 다음 우선순위만 갱신하는 write command로 설명
  - 예시 입력은 사용자가 준 형태를 기준으로 한다.
- README 문서와 CLI help에 `ai-ops pc next` 사용법을 추가한다.

## Test Plan

- `pc` help에 `next`와 `$pc:next` 설명이 노출되는지 확인한다.
- core 테스트:
  - ready context에서 `recordPcNextPriorities`가 workstream의 `다음 첫 행동`, managed priority block, backlog summary를 갱신하고 context commit을 만든다.
  - 동일 입력을 다시 적용하면 no-op commit이 된다.
  - item이 없거나 basis가 비어 있으면 실패한다.
  - active workstream/current entry가 없으면 기존 readiness reason을 포함해 실패한다.
  - managed files에 기존 dirty change가 있으면 실패한다.
- CLI/e2e 테스트:
  - built CLI로 `ai-ops pc next --item ... --basis ...`를 실행해 context repo만 변경되는지 확인한다.
- 검증 명령:
  - `npm test --workspace=apps/cli -- pc`
  - `npm run build --workspace=apps/cli`

## Assumptions

- `$pc:next`는 새 workstream을 만들지 않는다. workstream 생성은 계속 `$pc:add`가 담당한다.
- `$pc:next`는 handoff가 아니므로 draft/apply 프로토콜을 쓰지 않는다.
- 우선순위 목록은 “추가 inbox”가 아니라 active workstream의 현재 다음 우선순위 snapshot으로 다룬다.
- 사용자 선택에 따라 “목록 전체 저장 + 첫 항목을 다음 첫 행동으로 저장”을 기본 동작으로 확정한다.
